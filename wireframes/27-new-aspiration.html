What is an Aspiration Profile?

Each aspiration represents a different goal or project you're pursuing. You can have multiple active aspirations, each with:

  • Separate onboarding interview memory
  • Independent match recommendations
  • Unique scheduling and meetings

You can name it later if you prefer

Note: You'll go through a voice conversation with the agent to define this aspiration. All existing privacy and consent settings will apply.
